The model

One engine, three playbooks

Every specialty runs the same spine. What flexes is who deserves which response (Qualify) and what they get (Respond).

CaptureConcern- or procedure-led intake + guided photos
flexesQualifyValue × readiness × candidacy × budget → a route
flexesRespondSurgeon video · AI plan · assembled clips · async triage
BookInstant · virtual · in-person — with deposits
GrowNurture, memberships, rebooking, reviews

The two shaded steps are the new intelligence Aesthetic Virtual adds. Everything else is reused from SmileVirtual.

The new intelligence

Qualification routing

Never spend a $400/hr provider on a $12 lead — and never let a $20k lead get a form letter. A scoring engine sends each lead to the cheapest sufficient response.

value tier × readiness × candidacy × budget → route

Build economics

Reuse the spine, redesign the edges

♻️ Reuse from SmileVirtual

  • Shared data loop + lead model, status pipeline, heat & SLA
  • Practice console: work queue, triage, roles, notes/tags
  • Consult Studio (recorded video) — mainly for plastics
  • Closing page as the conversion surface
  • Landing pages, link-in-bio, widgets, directory
  • Settings, brand/theme, attribution & analytics

🎨 Redesign for aesthetics

  • The reward: sim → before/after galleries + instant pricing + plan preview
  • Intake + qualification routing logic (the new brain)
  • Response artifact: a Plan Builder replaces "record" for low value
  • Money first: packages, memberships, financing, deposits
  • Booking types + sensitive-photo consent handling
  • Compliance: HIPAA, before/after ad rules, telederm regs, injectable scope
Why practices pay

ROI by specialty

Plastic surgery
1 case ≫ cost

One extra $15k case/month dwarfs the subscription. Deposits cut no-shows; qualification protects scarce surgeon time. Highest willingness-to-pay.

Med spa
volume × attach

Convert more web leads to bookings and memberships at near-zero provider time. Rebooking cadence lifts lifetime value.

Dermatology
triage + convert

Async-triage throughput plus cosmetic conversion off the medical base. Reclaim low-value in-person slots for higher-value work.

Status & next steps

This is a vision artifact — the concept and strategy, not built apps. Full write-up in AESTHETIC_VIRTUAL.md. The existing SmileVirtual code is the reusable spine.

Suggested build order
  1. Plastic surgery first — ✅ patient capture flow built (procedure-led intake, confidential photos, qualification scoring, financing — no simulation). Next: reuse the Consult Studio + closing page + a console view for aesthetic leads.
  2. Med spa Plan Builder — the net-new surface: AI treatment plan as the response artifact + membership/package engine + approve-in-queue.
  3. Qualification routing engine — the shared brain that powers tiered responses across all three.
  4. Dermatology async triage — condition intake + AI pre-assessment + route, with compliance guardrails.
